# Arena+ — Beyond the Score

Midnight #0B1220; surface #18243A; electric lime #DFFF38; white #F5F6F8; energy coral #FF694D. Barlow Condensed is the display face, Inter the interface/body face. Google Fonts CSS is requested by the browser; Impact/Arial Narrow and sans-serif fallbacks keep content legible if unavailable. Self-host licensed WOFF2 assets before production for consistent performance/privacy.

Five homepage chapters provide a reading rhythm: an oversized typographic hero, six sport identities, an original editorial introduction to the archive, actual events, and upcoming events. There are no fictional article links, video buttons or invented sports narratives. The editorial panel leads to real archive browsing.

The hero and story artwork are original CSS geometry, visibly marked as illustration/photography placeholders. No unlicensed photography, league logos or provider fan artwork was downloaded. Replace placeholders only with approved assets, preserve aspect ratios, use picture/srcset with explicit sizes, and lazy-load below-fold images. There are currently no raster assets to optimize.

Football uses lime, F1 coral, MotoGP violet, basketball orange, rugby mint, and tennis pale green. Shared layout supports differences through CSS custom properties. Typography, shape and labels accompany color; status does not rely on color alone.

Native links, buttons, selects, details and tables provide keyboard behavior. A skip link, route announcer, visible focus outlines, headings and table captions support accessibility. Reduced motion disables transitions and GSAP. Motion is progressive enhancement; text remains visible without JavaScript animation.

Desktop uses three-column cards, tablet two, mobile one for events and two for arena links. Selectors stack on mobile. Long tables scroll inside their container. Feed errors preserve navigation and descriptive content.
